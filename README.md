# firecrawl-ecom-scraper

Este es un scraper de comercio electrónico que utiliza Firecrawl para extraer datos de productos de sitios web de comercio electrónico.

## Configuración

1. Clona este repositorio.
2. Instala las dependencias necesarias.
3. Configura las variables de entorno en el archivo `.env`.

## Ejecución

Para ejecutar el scraper, simplemente ejecuta el archivo `main.py`.
